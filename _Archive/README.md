# Historical archive

This tree contains preserved V1, V1.5, V2, and external reference source. It is
not part of the active UltraSim build or Godot project discovery surface.

Historical Godot manifests are retained beside their original source as
`project.godot.archived-reference`. Rename one back to `project.godot` only in a
separate checkout or workspace when intentionally opening that historical
project.

The archived `.csproj` and solution files are retained as documentation of the
old project boundaries. Explicit historical comparison adapters may compile or
run V2; active production projects must not reference archived source.
