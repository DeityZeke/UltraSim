# AIOS Topic Notes

This directory captures project-relevant topics that deserve durable memory but do not yet need a large canonical system document.

A topic may be small. That is intentional.

Each topic should ideally state:

- **Status**
- current preferred direction;
- important semantic rules;
- links to related canonical references;
- unresolved questions.

When a topic becomes fully covered by a canonical document, update `AIOS/TOPICS.md` and either reduce the topic note to a pointer or mark it SUPERSEDED.
