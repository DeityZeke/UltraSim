All ratios are **provisional topology evidence**. V2 uses one shared server socket. V3 evidence: one shared server UDP listener with bounded platform send/receive batching, one client socket and two secure protocol peers per bot. The matrix is an N0.10 input, not a direct production-topology verdict.

The common input/owner contract and canonical owner outcome match, but observer work is intentionally not normalized away. V2's chunk subscriptions and V3's maintained coarse outer envelopes produce different admitted observer sets; the `V2 observer items / V3 relations` and applied-record columns quantify that representation consequence. V2 does not expose authoritative input-ACK age, tier age, deadline-miss counts, actual wire bytes, bounded occupancy, syscall counts, security work, process CPU, or deterministic reservations; those cells are omitted rather than interpreted as zero.

V3 visible-state age/fairness is sampled during the untimed post-stage settle window, not charged to the tick comparison. The adapter reports the sampling window and histogram payload reservation explicitly. Age is the current observation time minus the authoritative creation time of the version still visible at the client, so continuously deferred latest-state debt remains visible rather than being discarded when a newer version supersedes it.
