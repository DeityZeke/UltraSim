## Implemented boundary and product behavior

- `Kernels/Audio` contains only engine-neutral value contracts and a generation-fenced, finite source budget (maximum 128 generic slots; the Godot product selects 16). It references no Godot/Game/Network implementation. `Client/Sound` maps 14 observed semantic events to 14 stable cue identities, composes gain and applies distance/time-based grounded footstep cadence. Game/server never chooses a WAV, native player, or audio device.
- The Godot adapter owns one listener, 16 reusable nonspatial/spatial player pairs, category gains (SFX/Ambient/UI), a 28 m world-source cull, one ambient loop, bounded priority admission and diagnostic counts. `MasterVolume` is still owned by client settings/Control Plane and now changes effective native playback live; zero volume suppresses playback without changing accepted Game actions. Category gain is presentation-local, not a new persistent settings owner.
- Fourteen deterministic, distinct, nonzero generated PCM WAV clips provide footsteps, jump/land, door, inventory, action, UI, notification and forest/wind ambience. They install through ordinary `world.local` Client.Content package/activation/CAS machinery. The only new passive file admission is exact mono PCM16 RIFF/WAVE with a 44-byte header, 22.05/44.1 kHz, at most 20 seconds and 2 MiB; malformed bytes and scope-inaccessible clips fail closed. Optional cache/audio failure skips sound, never authority.
- Local and Remote feed the same `ClientSoundEvent`/`ClientSoundEngine` cue selection. Local product acceptance asserts requested pickup/equip/jump/footstep and accepted door/jump transitions. Remote uses applied public world/equipment and presented actor motion rather than server-issued play packets. The existing exported mixed Local→Remote A→Remote B→Remote A→Local journey passed. UI click/open/close are local presentation events. Sound is not an Inventory mutation, server signal or Network protocol revision.
- Native `AudioStreamWav` and returned `AudioStreamPlayback` wrappers remain strongly owned until audio-server playback retirement. Session/adapter retirement stops sources and awaits bounded Godot process-frame cleanup before disposing streams and continuing application teardown. Generation replacement retains an old stream until its last playback is retired; the strong-reference native test waits for `NativeInstance == 0`. No forced GC, shutdown sleep, finalizer drain or native ownership registry was added.
