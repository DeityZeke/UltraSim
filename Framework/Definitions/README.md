# Typed Definitions (P4)

`Framework.Definitions` is a cold, engine-neutral composition seam. `StableDefinitionId` is authored/durable meaning; `DefinitionHandle` is a generation-fenced, process-local lookup index. Neither is an ECS entity, `PrefabKey`, or `PrefabHandle`. A Definition may have no prefab.

Contracts packages own stable `DefinitionFacetFamily<T>` identities and typed, immutable facet values. A package declares a Definition once; independent packages may contribute distinct facets through the same `DefinitionComposer`. Registration and validation happen before `Freeze`; normal reads bind dense typed tables and do not parse IDs, reflect, or allocate. A Contracts facet remains present when its optional runtime Core is absent. `RuntimeActive` reports selected capability availability; `RequireRuntime` instead rejects missing capability before authority. Selecting a capability is a composition decision, not a live setting.

The finite limits are 4,096 Definitions, 64 facet families, 32 facets per Definition, 256 tags, and 8,192 tag memberships. Duplicate Definitions/facets/memberships and conflicting aliases fail closed. Optional tag contributions to absent Definitions remain diagnostic-only; an explicitly required membership fails. Aliases are single-hop, same-owner mappings from an old authored ID to a present canonical Definition. Chains, collisions, and old-plus-new persisted duplicates reject. Persist stable IDs, never `DefinitionHandle`; a changed payload schema needs an explicit migration, not merely an alias.

The current first-party Iron Sword is registered through this public seam with Item, Inventory, Equipment, Combat, Durability, Skills, and Presentation facets. The Game composition derives its existing ECS prefab/inventory realization from those facets. Its prefab provenance is still a distinct existing ECS persistence contract; P4 does not reinterpret old ECS save bytes as Definition IDs. The representative Definition-reference save-set control separately proves stable authored-ID persistence and fresh-handle reconstruction.

`SemanticPresentationReference` names domain, Definition, and role—not a path or asset. The bounded public descriptor carries only that identity and public fallback bounds/visibility. It excludes Combat, Durability, and Skills data. The client can construct a primitive fallback without art. P4 does not add a general Definition wire format, derive Inventory portraits, or replace the existing World static descriptor protocol.

Compiled server-authoring packages use this same public composer in `Server/Scripts.P4`. The test loads two Contracts packages, optional Combat Core, and a Definition script; removes Core while retaining Combat meaning; then verifies a required-Core variant rejects before authority. `Game/Items.Contracts`, `Game/Combat.Contracts`, `Game/Skills.Contracts`, and `Game/Presentation.Contracts` are narrow meanings, not new Core implementations. They have no lateral Core dependencies.
